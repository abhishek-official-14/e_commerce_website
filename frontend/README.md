# E-Commerce Frontend (React + TypeScript + Vite)

## Stack

- React + TypeScript (Vite)
- Tailwind CSS
- React Router
- Axios
- Redux Toolkit

## Pages

- Home
- Product List
- Product Detail
- Cart
- Login/Register

## Setup

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
